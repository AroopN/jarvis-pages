Privacy policy

Last updated 12 November 2026.

Jarvis is a personal assistant used only by its owner. This policy covers the Google data it can reach.

What it accesses

  • Gmail: read-only, to search and read the owner's messages when asked.
  • Google Calendar: read-only, to list the owner's events.
  • YouTube: read-only, to search videos and list the owner's playlists, likes and subscriptions.

It cannot send, delete or change mail, events or anything on YouTube.

How it is used

Data is fetched only to answer the owner's own request at that moment. It is processed on the owner's home server and an AI model server the owner uses. It is not sold, not shared with anyone else, not used for advertising and not used to train AI models. Short notes of past conversations may be kept on the owner's home server so Jarvis can remember them.

Jarvis's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and removal

The sign-in token is stored on the owner's home server with access limited to Jarvis. Access can be removed at any time at myaccount.google.com/permissions.
